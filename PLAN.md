# Lerret

## What it is

Lerret is an open-source design canvas (MIT licensed). A folder of plain React
component files — `.jsx`/`.tsx` under `.lerret/` — renders as a pan/zoom canvas
of artboards. The source of truth stays as ordinary component files in the repo,
so the canvas is a view of real code rather than a separate design artifact.

Ways to use it:

- **CLI** — `npx @lerret/cli` in a project.
- **Hosted studio** — app.lerret.io.
- **Self-host** — run it yourself.
- **Claude Code plugin** — published through the
  [Belikely-United/marketplace](https://github.com/Belikely-United/marketplace):
  `/plugin install lerret@belikely-united`, then `/lerret`.

## Current plan

Grow through tutorials and organic discovery. No paid influencers.

Open work is tracked in the private repo `belikely-united/lerret-internal`:

| Issue | Work |
| --- | --- |
| #4 | Tutorials |
| #5 | Marketing video |
| #6 | Silent / organic strategy |

Tutorials (#4) are the main growth surface: they double as documentation and as
the discovery path for people who find the project through search or word of
mouth. The marketing video (#5) supports the same material in a different
format. The silent/organic strategy (#6) is the frame the other two work
under — no paid promotion, growth comes from people finding the tool and the
tutorials on their own.
